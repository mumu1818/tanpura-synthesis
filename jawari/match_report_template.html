What kind of mismatch is it?

The level difference of every partial in every frame (dB, clipped at 30) is split into three parts that add up in power. A smooth fixed tilt is what an EQ, a microphone or a different body could also cause. A fixed per-partial colour is a pattern over the partials that does not change in time, such as the pluck position or a body mode. Changes over time are what only the string and the jawari can produce.

RMS in dB of each part. The two real-vs-real rows show how big each part is between real plucks: the same pluck processed two ways, and another real pluck.

What the ear gets

A simple model of hearing turns each sound into loudness per hearing band over time. It is based on ERB bands, masking spread between bands (Schroeder) and Zwicker's loudness compression, with your recording's loudest moment set to 75 dB SPL. The model's gain is matched for equal average loudness. Quiet details that are masked or below the threshold of hearing count for little here, unlike in the dB maps above.

Is the loss measuring the right thing?

Each candidate distance was computed for four pairs per string:

  • the round-3 model against your recording;
  • the round-2 model against your recording;
  • the iTanpura file against your file, which is largely the same pluck processed differently, so this is a floor set by processing alone;
  • CS3Alt against the iTanpura file, which are two different real plucks.

The dot plot divides the model's distance by the "another real pluck" distance. At 1.0 the model is as different from your recording as another real pluck is from it. The gray tick shows where the same pluck processed twice sits. A good loss should put Sa (highlighted) on the left. Your ear puts it closest.

So how should the loss be computed?

    Your recordings

    Same-vibration test. For harmonics 4-30, the phase of one file relative to the other is followed over time; a constant pitch offset is allowed. If two files are the same vibration, that phase stays fixed: coherence 1.0. Independent plucks drift: about 0.4. The level residual is what is left after a fixed EQ per harmonic and a common gain over time (compression) are removed. The two control rows are made from your file with known processing. Fast, heavy compression lowers the coherence too (the Sa compressor control scores 0.52 against your file), so a "different pluck" reading is less certain than a "same pluck" one. No pair of independent plucks scored above 0.53.

    The processing between copies of the same pluck

    Fixed level difference per harmonic, each file relative to the iTanpura CS3 file (dB, 0 at partials 4-15). This is the EQ that turns one into the other.
